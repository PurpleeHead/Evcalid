# Evcalid

Одностраничный сайт, выполненный в рамках практики frontend-вёрстки.

Проект демонстрирует навыки создания структурированной и адаптивной веб-страницы с использованием HTML, CSS и JavaScript.

## 🌐 Demo

[Посмотреть проект](https://purpleehead.github.io/Evcalid/)

## 🛠 Технологии

* HTML5
* CSS3
* JavaScript
* SCSS
* Flexbox
* CSS Grid
* БЭМ
* Responsive Web Design
* Git / GitHub

## ✨ Реализовано

* Семантическая HTML-разметка
* Адаптивная вёрстка
* Flexbox и CSS Grid
* Работа с различными типами контента
* Стилизация интерактивных элементов
* JavaScript-интерактивность
* Оптимизированная структура проекта
* Корректное отображение на разных разрешениях экрана

## 📱 Адаптивность

Проект адаптирован под:

* Desktop
* Tablet
* Mobile

## 🎯 Цель проекта
